# **App Name**: My Messenger

## Core Features:

- Professional Real-time Hub: Enterprise-grade real-time text and media exchange (images/video) with specialized padding/spacing for a refined, professional chat interface.
- Universal Video & Voice Calling: Seamless high-definition calling featuring real-time duration tracking, mute toggles, and speaker controls within a custom animated UI.
- Smart Discovery Hub: Interactive search, friend suggestions with online indicators, and a dual-action request management system to grow your network.
- AI Productivity Assistant Tool: A dedicated tool accessed via the AI icon that uses reasoning to help draft complex responses, summarize threads, or provide information within a chat.
- Intelligent Navigation & Unread Badging: A WhatsApp-inspired four-tab footer (Chats, Discover, Calls, Settings) with dynamic unread message counts and fade transitions.
- Granular Privacy & Notification Controls: Centralized settings for read receipts, typing visibility, and fine-tuned notification channels for messages and calls.
- Context-Aware Interaction Engine: Device-optimized logic where desktop 'Enter' triggers message sends, while mobile uses an icon-based workflow with on-demand lazy permissions.

## Style Guidelines:

- Primary color: Deep Navy (#2A3D75), chosen to evoke stability and professional trust. Background color: Ultra-clean Cool White (#F6F8FC), creating an airy, focused interface with high contrast.
- Accent color: Sky Cerulean (#1D9BC9), an analogous hue that provides visibility for status indicators and active navigation elements.
- Headline and Body pairing: 'Space Grotesk' (sans-serif) for contemporary, technical headers and 'Inter' (sans-serif) for clear, machined, objective-looking message text.
- Sophisticated spacing grid focused on professional density, fixing common top/bottom padding issues found in amateur messaging clients.
- High-fidelity transitions: Smooth tab fading, pulsing incoming call animations, and progressive loading of message delivery status icons (✓, ✓✓).
- Line-style professional icons for navigation and status, with specialized teal coloring for read receipts and distinct red for missed call history.
